# Noeko
Noeko is an app for knowledge base management with a focus on semantic connections.


## Setup
Use the following overview to set it up.

### Step 1: Download Docker
Go [here](https://docs.docker.com/get-started/get-docker/) and get Docker.

### Step 2: Get Bun working
Go [here](https://bun.sh/) to download bun.

### Step 3: Clone this repository
> [!info] Access Rights
> You may need to ensure that you have git configured to authenticate with GitHub. I recommend using [GitHub's CLI](https://cli.github.com/) to do this.

Clone this repository locally:

```sh
git clone https://github.com/noekohq/Noeko.git
```

Then navigate to it

```sh
cd Noeko
```

### Step 4: Run the start command
```sh
bun run server
```

Now it should work, you'll see something like "Noeko server started at port 3400"
