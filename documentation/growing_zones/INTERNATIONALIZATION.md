# Ongoing Internationalization
For guidance on internationalization for new updates and features, see the [dedicated internationalization guide](../guides/INTERNATIONALIZATION.md).

Thus far, internationalization is an ongoing project as the scale of the internationalization update is quite broad and extensive. For about a year, development has taken place only in English, with no internationalization consideration. Now, we have the infrastructure and process in place to internationalize, but it will take some time to do so, even utilizing LLMs, because it needs to be done with intention.
